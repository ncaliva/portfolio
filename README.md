# Portfolio - Cloud Security e IA

Repositorio con los proyectos que desarrollo para formarme como ingeniero de Cloud Security, con conocimientos en IA y forense. Es un trabajo en progreso: voy sumando proyectos a medida que avanzo, así que el contenido crece de forma continua.

## Proyectos

| Proyecto | Descripción |
|---|---|
| [Proyecto 01 - AWS seguro](proyecto-01-aws-seguro) | Arquitectura segura en AWS para una aplicación web de una empresa ficticia: VPC con subnets pública y privada, EC2, S3 con logging, IAM con mínimo privilegio y CloudTrail (en progreso). |
| [Redes M2 - Flujo HTTPS](redes-m2-https-tls) | Flujo de establecimiento de una conexión HTTPS: DNS, TCP y TLS. |
| [Redes M3 - Firewall](redes-m3-firewall) | Segmentación de red y reglas de firewall para una tienda online ficticia. |
| [Redes Lab 1 - VPC](redes-lab1-vpc) | VPC en AWS con subnets públicas y privadas en dos zonas, Internet Gateway y NAT Gateway. |
| [Redes Lab 2 - Security Groups y NACLs](redes-lab2-security-groups-NACLs) | Security Groups (stateful) y NACL (stateless) sobre la VPC del Lab 1, con las reglas de firewall del diseño de M3. |
